# 독서 스터디

좋은 기술서는 혼자 끝까지 읽기 어렵습니다. 달레 스터디 독서 스터디는 한 권의 책을 정해진 기간 동안 함께 끝까지 읽는 스터디입니다.

한 명이 챕터를 요약해 발표하는 방식 대신, 매주 각자 흥미로웠던 부분, 깊이 파본 부분, 실무와 연결되는 부분을 메모로 남기고 그중 함께 이야기하고 싶은 주제를 골라 깊게 나눕니다.

## 1기: 데이터 중심 애플리케이션 설계

| 항목 | 내용 |
| --- | --- |
| 도서 | 데이터 중심 애플리케이션 설계 (마틴 클레프만) |
| 기간 | 2026/10/18 ~ 2026/12/06 (8주) |
| 모임 | 매주 일요일 21:00 ~ 22:00 KST, 달레 스터디 디스코드 음성 채널 |

## 진행 방식

1. 정해진 범위를 읽습니다.
2. 토요일 23:59 KST까지 [Discussions](../../discussions)의 **1기 메모** 카테고리에 글을 올립니다.
3. 함께 이야기해보고 싶은 글에 추천(위쪽 화살표)을 눌러주세요.
4. 모임에서는 추천이 많은 글 순서대로, 주제당 최대 15분씩 총 50분 동안 이야기를 나눕니다.

### 메모 작성 방법

- 제목은 `[N주차] 메모 주제` 형식으로 적어주세요.
  - 예: `[1주차] 응답 시간은 평균 말고 백분위로 봐야 한다`
- 흥미롭게 읽은 부분, 깊이 파본 부분, 실무와 연결되는 부분 중 하나면 충분합니다.
- 분량은 자유이며, 다른 분들이 어떤 이야기인지 알 수 있을 정도면 됩니다.

### 이야기 순서 정하기

- 해당 주차 말머리(`[N주차]`)로 검색한 뒤 **Top** 순으로 정렬해 순서를 정합니다.
- 추천 수가 같으면 먼저 올린 글이 앞 순서입니다.

## 참여 규칙

- 2회 연속 불참하시면 참여가 제한될 수 있습니다.

## 모임 에티켓

- 1기는 음성 중심으로 진행하며, 모두 카메라를 끄고 참여합니다. 진행 방식은 중간 회고 때 함께 다시 정합니다.
- 말하지 않을 때는 마이크를 음소거해 주세요.
- 한 주제는 최대 15분입니다. 이야기가 길어지면 진행자가 정리할 수 있습니다.
- 다른 의견도 존중해 주세요. 정답을 맞히는 자리가 아니라 관점을 나누는 자리입니다.
- 화면을 공유할 때는 글씨를 크게 확대해 주세요.
